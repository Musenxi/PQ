# backtests — tick 级重放回测

- `resim.py` — 用已记录的 ticks 重放狙击策略做参数对照（配对阈值、退出规则、趋势过滤等）。注意：Box 数据重放不能复现其实盘基线（差约 $18，主要来自可疑窗口的成交），故 Box 集合只信参数间的差值；VPS 集合在 0.95 阈值下精确复现其实盘结果。
- `tail5m_backtest.py` — BTC 5 分钟尾部买入回测：在最后 T 秒买入第一个进入 [0.95, 0.99] 的一侧（$10，7% 费）。683 个窗口重放结论：τ≤120 时失败率 8.6–12.1%（均价 0.965 隐含约 3.5%），平均每笔 −$0.57…−$0.95；τ 越小越差。机制：窗口末段的 [0.95, 0.99] 区间选出的恰是「尚未定局」的窗口。**已否决。**

主要回测结论汇总见 `docs/backtest-optimization-2026-11-17.md`。
