# PQ — Polymarket 量化策略纸面实验集

**作者 / Author: Musenxi**

2026 年 11 月在 Polymarket 上进行的一组系统化纸面交易（paper trading）实验：从一条 X 帖子的「Binance 领先 / Polymarket 滞后」延迟狙击说法出发，完整走完 **原型 → 干净长跑 → 独立复核 → 回测优化 → 多变体 A/B → 预注册裁决** 的流程。全部实验为纸面交易，未使用真实资金。

## 最终结论（2026-11-18 裁决）

| 策略线 | 样本 | 净盈亏 | 结论 |
|---|---|---|---|
| 延迟狙击 v0.3（Box） | 224 窗 | +$19.95（去水分 **−$11.56**） | 统计上为零（SE ±$63–71） |
| 延迟狙击 v0.5（VPS 基线） | 242 窗 | +$1.72 | 统计上为零（SE ±$58） |
| 狙击 v0.6（60 秒退出规则） | 229 窗 | −$96.90 | 同窗 A/B 输基线约 $105，**否决** |
| AC/VR（自相关+方差比） | 206 笔 | −$49.79 | **否决** |
| BTC 5m 尾部买入（回测） | 683 窗重放 | 每笔 −$0.57…−$3.9 | **否决**（失败率约为价格隐含概率的 3 倍） |
| 篮子套利扫描 | 约 2 天扫描 | 最大单次 +$0.51 | 真实机会存在但只有尘埃量级 |
| 慢速尾部跟踪 | 34 已结算 | −$10.88 | 继续观察（判读线 100 条结算） |
| 影子账户农场（60 账户） | 约 66 窗 | 五大家族合计约 +$326 | 继续观察（判读期 ≥1 周，看家族聚集） |

核心机制发现：狙击的「配对盈利」是路径选择而非套利——配对只在价格先朝入场方向移动 5–7 个点后才完成；未配对的第一腿持有到结算，胜率约 1/10。盈亏平衡需要约 85% 的持续配对率，实测 67–84%。

完整裁决见 [`docs/verdict-2026-11-18.md`](docs/verdict-2026-11-18.md)。

## 目录结构

- [`latency-snipe/`](latency-snipe/) — 主策略：Binance 领先信号 + Polymarket 盘口滞后的配对狙击（v0.3–v0.6 同一代码，参数区分），含东京行情中继 `binance_feed.py` 与三套部署的完整结果数据。
- [`acvr/`](acvr/) — AC/VR 变体：1 秒收益的滞后一阶自相关 + 方差比（q=5）双分支（动量/反转）。
- [`basket-arb/`](basket-arb/) — NegRisk 多结果事件的篮子套利扫描器（记录型，只扫描不下单），含完备性防陷阱设计。
- [`tail-tracker/`](tail-tracker/) — 慢速尾部「债券」跟踪：0.95–0.99 高胜率侧的纸面买入与结算跟踪（$50 资金框架，含影子条目）。
- [`shadow-farm/`](shadow-farm/) — 60 个影子账户农场：5 大策略家族 × 12 组参数共享同一行情与盘口流并行纸面运行，用于家族级筛选。
- [`backtests/`](backtests/) — tick 级重放回测工具（`resim.py`）与 5 分钟尾部买入回测（`tail5m_backtest.py`）。
- [`docs/`](docs/) — 策略规格、独立复核验证备忘、优化回测备忘与最终裁决报告。

## 方法论要点

- 结算口径：Chainlink 最后 60 秒 TWAP（非单点价格）；手续费按各市场 feeSchedule 的 taker 费率（BTC 5m 为 0.07）逐笔扣除。
- 所有盈亏数字双口径并列：含/不含一笔盘口退化期间的可疑窗口（+$31.51）。
- 变体存活标准在运行前预注册（pre-registered），裁决只按预注册标准执行。
- 外部（X 帖子）的盈利主张一律先用链上/公开数据核验再评估——本项目期间核验过的三个主张，两个被证伪或证伪其归因，一个为真但规模不可复制。
