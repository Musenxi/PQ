# basket-arb — 多结果篮子套利扫描（记录型）

每约 60 秒扫描全部 NegRisk 多结果事件（首个全集 239 个事件、3,299 个结果盘口），按各市场自身 feeSchedule 费率逐档吃 ask 阶梯，计算买齐全部结果（10/25/50/100/250 份/腿）的净利。

关键防陷阱设计：朴素 ask 之和会被「不完备结果集」主导（未上市结果获胜时所有腿归零）。事件必须带显式 "Other" 腿、或中间价之和 ≥0.97，才计为真实候选；陷阱至多每小时记录一次。接近盈利的事件以 5 秒间隔热重扫 300 秒。

- `arb_scan.py` — 扫描器（仅记录，不下单）。
- `results/opportunities.jsonl.gz` — 全部扫描机会日志；`scan_stats.jsonl` — 每小时统计。

结果：约 2 天内仅 6 个真实净正事件，最大 +$0.51（25 份规模），持续约 2 分钟——真实存在，但只有尘埃量级。
