# acvr — 自相关 / 方差比变体

对 1 秒 BTC 收益序列（180 秒回望）计算滞后一阶自相关 rho 与方差比 VR(5)：动量分支（rho>0.02 且 VR>1，顺最近 5 秒方向）与反转分支（rho<−0.02 且 VR<1，逆向），每个 5 分钟窗口最多一笔 $6 纸面入场（tau 30–150s，ask 0.15–0.92），持有到结算。

- `acvr_paper.py` — 由狙击代码分叉，信号数学经 AR(1) 合成序列单元测试。
- `results/` — VPS 独立运行数据：206 笔，−$49.79（手续费 $35.99）。盘中两次靠 0.15 底价「彩票单」单小时暴拉（+$82.85、+$38.85），均回吐。

裁决：未达预注册标准（净利 > 0），否决。信号本身大体已被盘口定价。
