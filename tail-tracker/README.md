# tail-tracker — 慢速尾部「债券」跟踪

每 5 分钟扫描 Gamma 二元市场：某一侧最优 ask ∈ [0.95, 0.99]、距结算 30 分钟至 60 天、clob 流动性 ≥ $2,000（排除 BTC 5m 市场），以 $10 纸面买入（走 ask 阶梯，VWAP ≤ 0.995），每个市场只入场一次。

$50 资金框架：最多约 5 个并发 $10 仓位为 funded，其余候选记为 shadow 条目并同样结算（争议/拆分按 0.5 结算并标记）。

- `tail_track.py` — 跟踪器。
- `results/` — `entries.jsonl`（全部入场）、`settlements.jsonl`（已结算）、`tail_stats.jsonl`（每小时统计）。

状态（2026-11-18 快照）：469 入场，34 已结算 −$10.88，2 笔全损；胜率 94.1%，低于该价位约 97% 的盈亏平衡线。判读标准：≥100 条结算且至少经历一次真实尾部事件后再下结论（约 2–4 周）。
